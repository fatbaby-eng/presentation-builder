This editor needs a local server

Opening index.html by double-click (file://) blocks the JavaScript modules, so the app looks blank or broken.

From this folder, run:

npm start

Or: npx --yes serve . — then open the URL it prints (usually http://localhost:3000). Exported presentations are still a single offline HTML file and do not need a server.
